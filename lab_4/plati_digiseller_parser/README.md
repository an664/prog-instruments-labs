# Парсер данных конкурентов с Plati.Market и Digiseller

Этот проект предназначен для сбора и анализа данных о продажах и рекламе с платформ Plati.Market и Digiseller.

## Установка

1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте `config/config.yaml` с вашими параметрами

## Использование

Запустите скрипт `scripts/run_parsers.sh` для сбора и обработки данных.

Результаты будут сохранены в папке `data/processed/`.

## Структура проекта

- `src/`: Исходный код
  - `parsers/`: Парсеры для Plati.Market и Digiseller
  - `data_processing/`: Обработка данных
  - `database/`: Управление базой данных
  - `visualization/`: Визуализация данных
- `config/`: Конфигурационные файлы
- `scripts/`: Скрипты для запуска и обслуживания
- `data/`: Собранные и обработанные данные
- `logs/`: Логи работы приложения
